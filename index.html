About AI editing

This version is a working file and image editor with limited natural-language commands, not a generative AI model. Unlimited free AI rewriting and prompt-driven image editing require an inference engine. A static GitHub Pages site cannot provide unlimited hosted AI computing for free. We'll add an optional local or user-provided AI connection without compromising the working editor.

PDFs, DOCX, XLSX and PPTX are not yet editable here. Unsupported files are rejected rather than silently damaged.
